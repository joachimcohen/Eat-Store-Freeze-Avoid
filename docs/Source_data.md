# Source data: Foodbank Victoria

These are the only timeframes the app may use, copied from [Foodbank Victoria, Expiry and Distribution](https://www.foodbank.org.au/expiry-and-distribution/) (page updated 20 Aug 2025). The project owner checks each row against the page before launch. They stay in the private prototype only until Foodbank gives permission.

Foodbank describes these as suggestions for charity partners, not legal advice, so the app words them as guidance. Non-food items (cleaning and pet products) are left out.
